# LifeTrace Execute 项目进度

更新时间：2026-08-27

## 1. 当前定位

LifeTrace Execute 是 LifeTrace 的独立 Android 执行中心客户端，负责日常执行场景，不承担财务模块。

当前已经完成核心信息架构确认，并建立浏览器高保真预览与 Android Compose 两套实现载体：

- `web-preview/`：当前 UI 设计、交互验证和快速评审基线。
- `app/`：最终 Android 客户端实现。

当前优先级是先把浏览器预览打磨到接近正式 Android 成品，再同步到 Compose，减少 Android Studio / SDK 环境对视觉迭代速度的影响。

## 2. 已确认的信息架构

### 一级导航

底部固定 5 个入口：

- 今天
- 任务
- 项目
- 日历
- 收集

### 非底部入口

- 我的：右上角头像进入。
- 今日复盘：从“今天”页面进入独立复盘页面。

### 功能保护原则

新增、重构、合并入口时不得删除已经确认的既有功能。

允许：

- 调整入口位置；
- 合并视觉入口；
- 优化页面层级。

不允许：

- 因新增功能删除项目、收集、复盘、账号/设置等已有能力；
- 为简化导航直接移除已确认页面。

## 5. 当前设计方向

视觉方向：

- 白色 / 极浅灰基础背景
- 蓝色主强调色
- 绿色表示完成 / 正向状态
- 橙色用于提醒、复盘和次级强调
- 红色仅用于高风险 / 高优先级 / 错误
- 浅边框 + 低强度阴影
- 高信息密度但避免传统后台管理式堆叠
- 使用正式 SVG / Material 风格图标，不使用字符占位图标

基准尺寸：

- 360 × 800 Android compact viewport
